# Personal Blog - Cloud Projects & Tech Insights

![Personal Blog](avatar.jpg)

## 🌟 Overview

Welcome to my personal blog repository! This is a professional blog focused on sharing insights about System Design, Software Architecture, Artificial Intelligence, Machine Learning, and Generative AI. The blog is hosted on AWS and uses a custom domain (cloudprojects.site).

## 🚀 Features

- Clean and modern responsive design
- Professional portfolio section
- Blog posts on tech topics
- Social media integration
- Contact form for professional inquiries

## 🛠️ Tech Stack

- HTML5
- CSS3
- Font Awesome Icons
- Google Fonts
- AWS Hosting
- Custom Domain (cloudprojects.site)

## 📋 Prerequisites

Before you begin, ensure you have the following:
- A code editor (VS Code recommended)
- Basic knowledge of HTML and CSS
- AWS Account (for hosting)
- Domain name (if you want to use a custom domain)

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/personalBlog.git
   ```

2. Open the project in your preferred code editor

3. Make your changes:
   - Update `index.html` for the main page
   - Modify `styles.css` for styling
   - Edit `resume.html` for your profile information

4. Test locally by opening `index.html` in your browser

## 🌐 Deployment

### AWS Hosting Setup

1. Create an S3 bucket:
   - Enable static website hosting
   - Configure bucket policy for public access
   - Upload all files to the bucket

2. Set up CloudFront distribution:
   - Create a new distribution
   - Point to your S3 bucket
   - Configure SSL certificate

3. Configure Route 53 (if using custom domain):
   - Create hosted zone
   - Add A record pointing to CloudFront
   - Update nameservers at your domain registrar

## 📱 Customization
